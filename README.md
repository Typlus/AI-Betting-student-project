# AI-Betting-student-project
This project will focus on the utilization of skills and tools involving AI to provide reasonably accurate predictions on sporting events. 

Goals: 
1: complete automation of the entire process (look at current available bets, research targets using data from record sites, create personal odds ands weigh how much money to place, place bet, correct weights and temperature, repeate if not out of money)
2. have an accuracy of  >50% in prediction records
3. ability to consistently 10x  10 dollars
4. safely allow for wallet to be given to system not just test money
5. maintain records of win/lost, amount placed, amount lost/gained and what it was placed on
6. utilize AI skills and tools as the main backbone of the project.
